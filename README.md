
# InspireHub - Motivation Quotes

**InspireHub** is a simple and modern web app that displays random motivational quotes to inspire users. Built using HTML, CSS, and JavaScript.

## Features
- **Random Quotes**: Displays a different motivational quote each time you click the button.
- **Responsive Design**: Works on desktop and mobile devices.
- **Modern UI**: Smooth gradient background and clean design.

## Live Demo
[View Live Project](https://mahibhavsar0012.github.io/inspirehub/)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mahibhavsar0012/inspirehub.git
   ```
2. Open `index.html` in your browser.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use
1. Click the **New Quote** button to get a random motivational quote.
2. Repeat as often as you need for inspiration!
